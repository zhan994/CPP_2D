# CPP_2D

***Simple 2D Coverage Path Planning (CPP) for UAVs.***

![](test/work/test_cpp_2d.png)

## Dependencies

- `boost-1.71.0.0ubuntu2`
- `gnu-plot`

```bash
sudo apt install libboost-dev gnuplot
```

## Run

```bash
git clone git@github.com:zhan994/CPP_2D.git
cd CPP_2D
mkdir build && cd build
cmake ..
make -j

# Example test 
./test_work_route_2
```
